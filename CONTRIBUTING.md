# Contributing to ScriptedSMP

Contributions are welcome! Before submitting changes, please read the guidelines below.

## Requirements

- **Java 25** (must match the project's configured Java version).
- Git.
- An IDE capable of working with Gradle projects. (Like Intelji IDEA)

## Development Guidelines

- Follow the existing project structure and coding conventions.
- Use clear and descriptive names for classes, methods, and variables.
- Add **Javadoc** to all new public-facing API classes, methods, and fields.
- Try to keep API implementations separate from their public interfaces.
- Avoid unnecessary dependencies.

## Building

Before submitting a contribution, make sure the project builds successfully:

```bash
./gradlew build
```

## Pull Requests

When submitting a Pull Request:

- Provide a clear title and description.
- Explain what your changes introduce or fix.
- Include relevant testing information.
- Ensure the project builds successfully.
- Address any requested changes during review.

All contributions are to be reviewed before being merged.

Thank you for contributing to ScriptedSMP!
