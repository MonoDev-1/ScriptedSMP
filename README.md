# ScriptedSMP

ScriptedSMP is a Paper plugin that provides a foundation for developing custom, scripted Minecraft SMPs.

## API

ScriptedSMP exposes a dedicated API for developers to build extensions and custom systems.
All public facing API methods are documented with Javadoc.

Current API components:
- **Event Framework:** A custom event system that allows developers to handle ScriptedSMP events.
- **Configuration Registry:** A centralized registry for defining and managing configuration entries.
